# Support

Use the channel that matches your request.

| Need | Where to go |
|---|---|
| Bug report | [Open a bug report](https://github.com/LloydCoder/hezqen/issues/new?template=bug_report.yml) |
| Feature request | [Request a feature](https://github.com/LloydCoder/hezqen/issues/new?template=feature_request.yml) |
| Usage and setup questions | Read the [documentation index](docs/README.md), then open a GitHub issue if the answer is not covered |
| General project enquiries | hello@tinlance.com |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md); do not use public issues or this general support address for exploit details |

When requesting help, include the relevant commit or version, runtime, operating system, commands executed and sanitized error output. Remove credentials, tokens, personal data and private evidence before sharing logs.

HEZQEN is under active development. Support is provided on a best-effort basis; no commercial support or response-time guarantee is implied.
