# Changelog

All notable changes to HEZQEN are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and version numbers will follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html) when stable releases begin.

This changelog starts with the current public repository baseline. Earlier development history is not reconstructed retrospectively.

## [Unreleased]

### Added

- Public Next.js application shell with homepage, About page, editorial standards page and four editorial division routes.
- HEZQEN Labs VRAM sizing and API-versus-self-hosted AI cost calculators, with documented methodologies and domain tests.
- Payload CMS integration with PostgreSQL adapter, admin/API route mounting and restricted editorial, source, evidence, claim and audit collections.
- Human-controlled editorial workflow state machine and publication policy validation.
- Research source/evidence validation and guarded HTTPS evidence acquisition logic.
- Architecture, editorial, security, research provenance, data model, CMS and infrastructure documentation.
- GitHub Actions quality, dependency maintenance and isolated Payload migration workflows.

### Changed

- Repository documentation and community health guidance are being standardized for external contributors.
- LLM-facing documentation entry points are being added for the public site.

### Not yet available

- No stable release has been published.
- Initial application database migrations, production CMS acceptance, persistent evidence storage, reader accounts, search and premium subscriptions remain incomplete.
