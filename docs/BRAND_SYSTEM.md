# HEZQEN Brand System

**Source of truth:** HEZQEN Logo Kit & Usage Guidelines v1.0, November 2026.

## Logo assets

The supplied SVG artwork is used directly. The horizontal color logo is for light surfaces; the reversed horizontal logo is for dark surfaces. The favicon SVG is used as the site icon. Do not redraw, retype, recolor, stretch, rotate, add effects to, or alter the proportions of supplied marks.

## Color tokens

| Token | Hex | Use |
|---|---|---|
| Navy | #0B1B33 | Primary brand surface and text |
| Graphite | #2A3441 | Secondary dark text |
| Amber | #F5A623 | Signal accent only |
| Amber Deep | #A35F00 | Readable amber text on light backgrounds |
| Slate | #5B6678 | Secondary text |
| Mist | #F4F5F7 | Light surface |
| White | #FFFFFF | Primary background |

Target visual balance is approximately 75% white/mist, 18% navy, 5% graphite and 2% amber. Amber on white is decorative only and must not be used for body text.

## Typography

Use Inter for general text and Inter Display for large headlines where available. The initial implementation uses an Inter-first system stack until font files are packaged locally. Use a system monospace stack for code and calculator outputs.

## Logo sizing and clear space

Maintain at least 1X clear space around the mark, where X is half the height of the wordmark capitals. The horizontal compact logo must not render below 120 px wide on screen. Use the icon mark for small app/favicons; below 32 px use the supplied small-size bold icon or favicon artwork.

## Backgrounds and co-branding

Use the color logo on white/mist and the reversed logo on navy/graphite. On photography, use a single-color version over a calm, even area. When co-branded with Tinlance, maintain equal visual weight and at least 2X spacing with a thin vertical divider.
