# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not publish exploit details, credentials, private data or unpatched vulnerability information in a public issue.

## Scope

Security reports are welcome for the HEZQEN application, editorial workflow, evidence handling, authentication and authorization, integrations, build and deployment configuration, and public-facing tools.

## Handling

Reports should include affected component, impact, reproduction steps, relevant versions and any safe proof of concept. Avoid accessing or modifying data that is not yours. The maintainers will assess severity, coordinate remediation and publish an advisory when appropriate.
